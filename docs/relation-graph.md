# 代码关系图说明

## 当前能力

前端新增“代码关系图”页面，入口位于工作台侧边栏的“代码关系图”。项目已读取时，页面调用后端项目图接口，展示当前 ZIP 中已由 AST、符号索引和显式导入解析确认的函数调用关系；如果接口暂时不可用，则回退到当前分析报告中的证据关系。页面展示：

- 直接影响：报告已确认本次签名变化引入不兼容的调用；
- 1 层 / 2 层间接影响：位于直接影响上游的待检查调用路径；
- 已确认调用：静态目标已确认，但报告未将其标为本次变更的直接影响；
- 函数节点、调用边、文件位置和行号；
- 当前影响链和右侧关系证据。
- 项目函数清单、图谱覆盖状态和未解析调用数量。

前端只展示项目图接口或当前报告提供的真实关系。直接影响高亮按调用方、目标、文件、行和列匹配报告；同一行的不同调用保留各自定位。报告回退模式逐条展示真实路径，共用终点的分支不会拼成一条链。刷新页面后，当前会话报告可能被清空，需要重新分析或从历史报告打开来源项目。

## 显示范围（2026-10-27）

完成函数签名分析后，默认显示“本次变更”：仅展示目标函数、报告中的直接影响及有证据支持的 1 层 / 2 层上游传播路径。节点按实际标识匹配定义位置，调用边保留文件、行、列身份；兼容调用和其他函数不会混入该视图。零影响报告只显示真实目标，不借用普通调用制造影响路径。

“项目全图”保留全部项目节点与已确认调用，可随时切换查看。切换时清空当前搜索和节点选择，新报告恢复默认聚焦；尚未产生函数报告时沿用项目全图。节点、调用与直接影响计数属于当前视图，“项目待确认调用”单独标明全项目范围。搜索、定位和右侧关系卡均只使用当前视图的节点与调用。

这项过滤只改变展示，不删除接口数据、不改报告或覆盖结论。隐藏的节点不等于已确认无影响，上游传播仍表示建议检查。模块与符号报告不转成函数影响图。项目图接口暂时不可用时，仍可展示报告内的真实证据路径。

## 演示方式

使用 `signature_change` 示例，选择 `utils.format_date`，新增必填参数 `timezone` 并完成分析。完整示例应展示：

```text
page.page → dashboard.dashboard → report.report → utils.format_date
```

其中直接关系和上游待检查关系使用不同颜色，点击节点或关系卡片可以查看对应证据位置。

不超过 12 个节点时使用轻量力导向布局：节点之间保持距离，调用边提供弹性拉力，并带有缓慢的独立游移；文字和调用箭头同步移动。更大图谱使用静态网格，避免逐帧两两计算。项目全图保留全部节点和调用边，画布以可读比例展示局部，不把整张大图压缩到一个屏幕内。

画布支持滚轮缩放、空白区域拖拽平移、节点拖动，并提供放大、缩小和恢复布局按钮。下方清单支持按函数标识或文件搜索，点击结果可定位节点；键盘聚焦节点时也会同步定位。小图另提供暂停/继续按钮。页面进入后台时暂停动画；系统开启“减少动态效果”时保持静止，仍可拖动、缩放和选择节点。动态布局仅用于展示，不改变调用关系或分析结论。Windows 原生 reduced-motion 人工补验继续记录为 pending。

## 当前边界

当前项目图展示函数调用与必要的真实调用上下文。模块报告和符号报告仍只在报告页展示对应分析结果；此图不推断对象动态分派、变量关系或外部服务。除模块级函数外，已确认调用的类方法、嵌套函数、类定义体和 lambda 调用方都有端点节点，但这些上下文不会增加 Inspect 的可选变更目标。未解析调用、语法错误和不支持的调用范围会进入诊断，不会被画成确定边。

## 后端接口

项目上传关系图接口：

```text
POST /api/v1/projects/graph
```

表单字段为 `file`、可选 `expected_fingerprint` 和可选 `analysis_root`。项目库快照使用：

```text
POST /api/v1/snapshots/{snapshot_id}/graph
```

返回的 `graph` 字段包含已解析的节点和边，`diagnostics` 区分未解析调用、解析错误和不支持范围，`coverage` 提供可读的覆盖状态。例如：

```json
{
  "graph": {
    "nodes": [{"id": "report.report", "kind": "function", "file": "report.py", "line": 1}],
    "edges": [{"source": "dashboard.dashboard", "target": "report.report", "kind": "call", "location": {"file": "dashboard.py", "line": 5}}]
  }
}
```

后端会保留源码位置和解析依据；前端只将当前报告中的目标函数和直接影响调用高亮，不能用前端 Mock 节点冒充静态分析结果。
